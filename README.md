# 洲际电竞 · 第一版业务演示

本地可操作原型，包含玩家商城、打手工作台和商家后台。不是已接微信的小程序，不具备生产支付、身份认证或服务端授权。所有金额、人员与交易都是演示数据。没有使用参考截图中的游戏角色或商家素材。

## 启动

需要 Node.js。进入此目录运行 `node server.mjs`，打开 http://127.0.0.1:4173 。使用 `node --test tests/domain.test.mjs` 运行业务规则测试。

也可运行 `启动演示.cmd`。服务只监听本机，不会发布到公网。关闭启动窗口即可停止。

## 体验流程

1. 玩家商城：选择套餐、填写虚构资料、创建订单并模拟支付。
2. 打手工作台：默认人员北辰尚未缴保证金；到“我的保证金”同意规则并模拟缴纳。
3. 商家后台：为订单安排北辰。
4. 打手工作台：接单、服务、填写完成记录并提交验收。
5. 玩家订单：确认完成，也可申请全额售后退款。
6. 打手保证金：申请退出。
7. 商家后台：待人员未结订单及纠纷清零后审核退还，再模拟渠道成功或失败。

山海初始有一笔服务中订单和500元保证金，可用于体验退还阻断。青禾初始待审核，可用于体验审核流程。

## 当前范围

- 后台：动态经营概览、订单筛选搜索、派单改派、人员审核、保证金账户与流水、退还审核、订单售后、失败重试、套餐名称/价格编辑及上下架、CSV导出、操作日志。
- 玩家：套餐选择、订单创建、模拟支付、未支付取消、验收、全额售后申请。
- 打手：保证金缴纳、接单/拒单、履约文字记录、退出、退还进度、重新入驻。
- 保证金与玩家订单款独立记录；退款受理不扣余额，确认成功才扣余额；重复完成被拦截。

## 数据与安全边界

数据保存于此浏览器 localStorage，角色按钮只是演示切换，不能当作权限安全。不要输入真实客户资料、证件、银行卡或凭据。不同设备不共享数据。同浏览器标签页可刷新同步，但没有并发写入保护。刷新保留业务数据；演示说明页提供重置。

本版无真实资金托管、扣款、罚款、打款。业务上的退还限制不等于银行或微信冻结资金。不能用于真实营业。

## 正式版本待办

1. 明确经营主体、游戏服务及保证金的支付准入、商户账户归属、365天以上保证金退还安排。
2. 独立登录、服务端角色授权、对象级权限、数据库事务、备份与恢复、审计。
3. 支付签名、回调验证、金额校验、幂等、补单、对账、退款异常恢复与真机联调。
4. 部分退款、保证金争议金额与证据、扣款申诉和复核流程（本版只阻止有未结纠纷的人员退还）。
5. 多人员协作、排班、收入分佣与结算、附件、通知、可配置游戏和复杂套餐。
6. 小程序页面适配、隐私说明、平台审核、支付权限、真实上线验收。

原型中的保证金500元、套餐及规则仅用于讨论，不是合同或正式经营规则。

## 商城展示升级（2026-10-31）

玩家商城新增单列/双列切换（浏览器记忆）、套餐搜索、推荐区、手游/端游预选、分类/小时单筛选、价格排序、收藏、下单帮助与入驻说明、手机底部导航。演示套餐增加为六款；旧存档会补入缺少的新套餐，不覆盖已有套餐价格和上下架状态。当前六款套餐均支持端游和手游，端选择影响展示标签及下单表单默认值。

布局与收藏属于当前浏览器的展示偏好，不是商家全店默认配置，也不跨设备同步。商品封面为本地CSS绘制的示意图；咨询入口为流程说明，尚未连接真人客服。
